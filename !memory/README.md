# Общие материалы

Здесь лежат заметки и вспомогательные материалы, которые относятся ко всем
предметам. Файлы конкретной лабораторной остаются в папке её предмета.

- `LAB_REPORT_STYLE.md` - памятка по оформлению отчётов. Главный образец:
  `../vp/1/ЛР1_отчёт.odt`.
- `var/` - перенесённый технический кэш шрифтов, не учебные материалы.

Новые общие заметки сохранять здесь, чтобы не смешивать их с папками `ii`,
`mikov`, `ml` и `vp`.

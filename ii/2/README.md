# Лабораторная 2. Базовые конструкции OWL

В `ontology.ttl` RDF-модель дополнена классами, подклассами, свойствами,
областями определения (`rdfs:domain`), областями значений (`rdfs:range`) и
конкретными объектами. Например, `LiveMode` является подклассом `Mode`,
а объект `liveVoice` относится к классу `LiveMode`.

Файл можно открыть в Protégé через **File -> Open**. Он записан в формате
Turtle, который Protégé понимает. При необходимости выбрать отображение
меток `rdfs:label`, чтобы увидеть русские названия.

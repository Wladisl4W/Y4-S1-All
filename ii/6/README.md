# Лабораторная 6. Правила SWRL

Тема та же: приложение для тренировки интонации. `ontology.ttl` содержит
классы, свойства, учебные экземпляры и пять правил SWRL. Те же правила
записаны в коротком виде в `rules.swrl` для чтения и вставки в SWRLTab:

1. Черновая линия, которую исправляет пользователь, считается исправляемой.
2. Пользователь, исправляющий линию, является её редактором.
3. Распевка с целевой нотой относится к распевкам с целью.
4. Результат ниже 60 % отмечается для повторения.
5. Распознанная частота ниже 60 Гц отмечается как вне диапазона.

Значения 42 % и 45 Гц в онтологии **синтетические**, только для демонстрации
правил; это не измерения из дипломного приложения. После вывода ожидаются
классы `EditedDraft` для `draftMelody`, `DraftEditor` для `singer`,
`TargetedExercise` для `warmup`, `NeedsPractice` для `exerciseResult` и
`OutsideVoiceRange` для `detectedNote`.

В Protégé нужно открыть `ontology.ttl` и включить вкладку SWRLTab (если она
установлена), чтобы увидеть правила. Для их выполнения нужен механизм,
поддерживающий SWRL и встроенное сравнение `swrlb:lessThan`. Обычный
RDF-парсер только проверяет структуру онтологии и не запускает правила.

# ЛР1: RDF и OWL

`ontology.ttl` описывает приложение, три режима, четыре исходных паттерна, набор и три допустимых примера маршрута. Числа взяты из классов `Exercise`, `ExerciseCatalog`, `WarmupRoute` дипломного проекта. RDF-тройки задают факты, а OWL-классы и свойства — структуру модели. Файл можно открыть в Protégé.

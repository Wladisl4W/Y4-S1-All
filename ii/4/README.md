# Лабораторная 4. Профили OWL

Из трёх профилей OWL 2 здесь выбран **OWL 2 RL**. Он удобен для вывода новых
троек по правилам из существующих данных. В `ontology.ttl` для этого показаны:

- наследование класса: `Mode` является подклассом `Feature`;
- обратное свойство: из `trainer hasMode warmup` следует
  `warmup modeOf trainer`;
- цепочка свойств: из `trainer hasMode warmup` и
  `warmup showsNote targetNote` следует `trainer canShow targetNote`.

Другие профили решают иные задачи: EL удобен для больших иерархий классов,
QL для запросов к большим данным, RL для вывода правилами. Этот файл
демонстрирует характерные для RL конструкции; точную формальную проверку
принадлежности профилю нужно делать профильным валидатором OWL.

Файл можно открыть в Protégé. Для проверки трёх выводов локально использован
RDF-парсер и механизм OWL-RL (`owlrl`); результат записан в `inferences.txt`.

# ЛР4: SWRL

В `ontology.ttl` записаны семь правил; `rules.swrl` содержит их читаемую форму. Шесть правил выявляют сомнительные значения, одно вычисляет ожидаемую длительность упражнения как число нот × секунд на ноту. Это адаптация задания пособия про расчёт автономности ноутбука к теме диплома.

`check_rules.py` проверяет RDF-структуру и повторяет условия правил на утверждённых данных. Результат сохранён в `results.txt`. Скрипт **не является SWRL-движком**; выведенные SWRL-аксиомы им не получены. Для запуска правил в Protégé нужен совместимый движок с поддержкой `swrlb:multiply` и сравнений.

# Лабораторные по интеллектуальным информационным системам

Тема примеров: дипломное приложение для тренировки интонации. Основной
источник заданий: `files/Модели И.С..docx`. Нумерация папок продолжает
готовый RDF-граф в папке `1`, поэтому она на один шаг отличается от нумерации
занятий в методичке.

| Папка | Содержание | Раздел методички |
| --- | --- | --- |
| `1` | RDF-граф приложения | Занятие 2 |
| `2` | Базовая OWL-онтология | Занятие 3 |
| `3` | Расширенная OWL-онтология | Занятие 4 |
| `4` | Возможности профиля OWL RL и логический вывод | Занятие 5 |
| `5` | SPARQL-запросы к онтологии | Занятие 6 |
| `6` | Правила SWRL | Занятие 7 |

Каждая папка содержит свой README с объяснением и инструкцией. В папке `5`
сохранён результат выполнения запросов. Правила SWRL в папке `6` записаны в
онтологии, но их выполнение требует отдельного SWRL-совместимого механизма.

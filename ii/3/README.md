# Лабораторная 3. Расширенные конструкции OWL

Файл `ontology.ttl` продолжает онтологию из папки 2. Добавлены два определяемых
класса (`owl:equivalentClass` с ограничениями):

- `ExerciseWithTarget`: режим распевки, у которого есть целевая нота.
- `EditableDraft`: черновая нотная линия со свойством `needsReview = true`.

Класс для объектов `warmup` и `draftMelody` не указан вручную: его должен
вывести механизм рассуждений. Кроме того, `storedIn` обратно свойству
`containsResult`, поэтому из «результат хранится в истории» выводится
«история содержит результат». Три вида режимов объявлены несовместимыми.

В Protégé откройте файл, запустите **Reasoner -> Start reasoner**, затем
посмотрите inferred types для `warmup` и `draftMelody`.

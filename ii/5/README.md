# Лабораторная 5. Запросы SPARQL

Шесть запросов в `queries/` работают с онтологией из `../4/ontology.ttl`:

1. Найти режимы приложения и их названия (`FILTER`, `ORDER BY`).
2. Найти целевые ноты распевок.
3. Узнать, где хранится результат занятия.
4. Найти линии, которые может исправить пользователь (`OPTIONAL`).
5. Найти ноты, которые может показать приложение после OWL-RL вывода.
6. Посчитать число режимов (`COUNT`).

Для проверки был запущен `run_queries.py`, а ответы сохранены в `results.txt`.
Повторить можно командой из этой папки:

```bash
uv run --no-project --with rdflib --with owlrl python run_queries.py
```

В Protégé текст каждого `.rq` можно вставить в SPARQL Query; для запроса 5
понадобится сначала применить логический вывод, потому что `canShow` не задано
в файле явно.

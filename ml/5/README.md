# Лабораторная работа 5 — классификация грибов

`lab5.py` выполняет все пункты методички для `mushrooms.csv`:

1. Проверяет размер набора, типы, пропуски, повторы и распределение классов.
2. Предсказывает съедобность (`e`/`p`) тремя методами.
3. Предсказывает местообитание семи классов пятью методами.
4. Предсказывает три характеристики пластинок по отдельности и вместе шестью методами.

Для каждой модели выводятся Accuracy, Precision, Recall, F1, AUC-ROC и матрица ошибок. В `results/metrics.csv` сохранена общая таблица; там же находятся изображения матриц ошибок и деревьев решений. На рисунках деревьев показаны первые четыре уровня обученной модели, чтобы подписи оставались читаемыми.

## Как читать результаты

- Для съедобности положительным классом считается `p` (ядовитый гриб).
- Для отдельных бинарных задач о пластинках положительные классы: `a` для прикрепления, `w` для расстояния, `n` для размера.
- В многоклассовых задачах Precision, Recall и F1 усреднены с весами по числу объектов классов; AUC-ROC вычислена методом One-vs-Rest.
- Строки матрицы ошибок — фактические классы, столбцы — предсказанные. Числа на диагонали означают правильные ответы.
- Пропуск `?` в `stalk-root` сохранён как отдельная категория. Категории кодируются после разделения на обучение и тест, только по обучающим данным.
- В задачах о пластинках все три прогнозируемых характеристики исключены из входных признаков, включая совместную задачу.

В CSV для характеристик пластинок реально встречается по **два** значения в каждом отдельном столбце, хотя описание в методичке перечисляет больше возможных вариантов. Совместная задача содержит **пять** встретившихся комбинаций.

Результаты относятся к этому учебному набору данных и не предназначены для определения безопасности собранных грибов.

# Индивидуальное задание 9

Прогноз медицинских расходов по `insurance.csv`. Полное воспроизводимое решение находится в `ind9.py`, а упрощённый учебный вариант — в `ind9_basic.py`. Объяснение и графики — в `ИЗ9_отчёт.docx`.

## Запуск

Нужен Python 3 и библиотеки из `requirements.txt`. На этом компьютере подготовлено отдельное окружение с ними. В терминале один раз выполните:

```bash
source /home/wladisl4w/.local/share/uni4-ml-venv/bin/activate
```

После этого обычная команда `python3` увидит `scikit-learn`. Запустите:

```bash
python3 ind9.py
```

Программа читает `insurance.csv` рядом с собой независимо от текущей папки. Она печатает шаги 1–14 и сохраняет четыре рисунка и `metrics.json` в `results/`.

Второй вариант использует только приёмы из лабораторных работ и индивидуального задания: операции pandas, графики matplotlib, линейную регрессию и K-fold из scikit-learn. Для него перейдите в `ml/ind` и запустите:

```bash
python3 ind9_basic.py
```

Этот вариант показывает четыре графика на экране и печатает те же метрики. Он не создаёт файлы результатов; отчёт повторно составлять не нужно.

## Как проверяется модель

Данные делятся на 70% для обучения и 30% для итоговой проверки (`random_state=42`). При пятикратной кросс-валидации признаки выбираются отдельно внутри каждого обучающего фолда. Тестовые данные используются только для последней оценки.

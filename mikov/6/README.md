# ЛР6. Устойчивость системы с задержкой

Модель: `a2*x'' + a1*x' + a0*x = k*(1 - x(t-tau))`.
Начальные значения `x=0`, `x'=0`; цель равна 1. В опытах `a2=a0=1`, шаг времени `0,01 с`.

## Запуск

```bash
g++ -std=c++17 -O2 -Wall -Wextra -pedantic main.cpp -o lab6
./lab6
```

Программа записывает `critical_delay.csv` и три файла `response_*.csv`. Для обновления графиков и Word-отчёта запустить `python3 build_report.py` (нужны `matplotlib` и `python-docx`).

## Что сказать на защите

1. Регулятор получает значение `x` не сейчас, а `tau` секунд назад.
2. На каждом шаге я по уравнению вычисляю ускорение, затем скорость и новое положение. Прошлые положения лежат в массиве.
3. В конце опыта сравниваю размах отклонений в двух временных интервалах. Если размах увеличился, система неустойчива.
4. Двоичным поиском нахожу задержку, рядом с которой затухание сменяется ростом колебаний.
5. При `a1=1`, `k=2` граница около `0,565 с`: `0,415 с` устойчиво, `0,715 с` неустойчиво. Большее усиление `k` уменьшает допустимую задержку, а большее `a1` увеличивает её.

Граница приблизительная: она зависит от шага `0,01 с`, времени наблюдения `300 с` и правила сравнения колебаний. Значение `x` стремится к `k/(a0+k)`, а не к 1, потому что в модели есть член `a0*x`.
